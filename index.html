案例 01 · 白底主图

主体居中、背景干净的合规首图

首图的任务是让顾客在一屏之内看清商品。我用「柔和棚拍光 + 纯净白底 + 主体居中」作为固定方向，出图后统一做三件事：抠净背景、把底色压到纯白、按平台规格等比留白并导出 1000×1000。

  • 背景：底色统一压到 #FFFFFF，不留灰底与杂色，避免平台判为「背景不干净」。
  • 主体：等比缩放后留 8% 安全边距，避免主图被平台裁切或与角标重叠。
  • 细节：边缘做轻锐化，保留缝线与纽扣的辨识度。
1000×1000 纯白底 #FFFFFF 等比留白 8% 边缘锐化
案例 02 · 多色 SKU 批量产出

锁定构图，只换颜色：一次产出 5 个色号

同款连衣裙需要同时上架藏青、黑、奶白、砖红、墨绿五个颜色。做法是把「构图 / 机位 / 光源」在链路里固定住，只对色相与明度做映射，因此五个色号的褶皱走向、投影位置、面料光泽完全一致 —— 顾客在 SKU 之间切换时画面不会跳。

构图锁定 只换 H/S/L 三通道 保留褶皱与投影 五金件固有色保护 批量产出
案例 03 · 详情页排版

首屏 Banner 与详情页长图

详情页按「首屏氛围 → 面料特写 → 版型细节」的信息层级往下排。首屏左侧留出文案区，避免卖点字压到商品；面料与细节模块统一按 1000px 宽输出，保证拼接后不出现尺寸跳变。

案例 04 · AI 出图 → 精修

出图不等于成品：从「能用」到「能上架」

初版出图底色偏灰、色温偏冷、牛仔蓝发闷，直接上架会显得「廉价」。下面四步是固定动作，做完才能交付出图。

  • 白平衡归正：以画面中性区为参考校色，去掉整体冷偏。
  • 黑白场拉伸：把底色提到纯白、暗部压实，画面立刻「通透」。
  • 自然饱和度：按区域彩度加权，牛仔蓝提上来，同时避免白 T 恤与肤色过冲。
  • 背景净化：收尾把底色压到 #FFFFFF —— 这一步不做，边缘会出现一圈发光光晕。
案例 05 · 流程沉淀

把一次成功变成可复用模板

同款多色能一次跑通、第二天换个人也能做出一样的图，靠的是把变量固定下来。下面是我按品类沉淀的模板结构。

固定项（不改）
  • 构图与机位：正面平视、主体居中
  • 光源：柔和棚拍光、左上方主光
  • 背景：纯净无缝白底、无杂物
  • 质感词：商业产品摄影、结构准确
变量项（只改这里）
  • 颜色：色相 / 明度 / 饱和三值
  • 材质：针织 / 梭织 / 牛仔 / 牛仔水洗
  • 品类结构：领型、门襟、腰带有无
  • 场景：棚拍纯底 / 居家氛围 / 通勤
沉淀物（交接用）
  • 可复用 Prompt 模板 + 负向词库
  • 该品类的高频错误清单（手部、纽扣、纹理）
  • 导出规格表：尺寸 / 底色 / 留白 / 命名规则
  • 素材归档结构：按品类 + 用途分层

04 / 标注标准

服饰标注标准理解

标注工作的基础是对标准的准确理解，以下为核心标注维度与边界判定示例

一一级品类标注标准 含易混淆区分要点

一级品类定义包含子类易混淆区分要点
上衣上半身穿着的服饰T恤、衬衫、卫衣、毛衣、西装、马甲与连衣裙区分：上下分体 = 上衣，上下一体 = 连衣裙
裤装下半身穿着的裤类牛仔裤、休闲裤、短裤、西裤与半身裙区分：有独立裤腿结构 = 裤装
裙装下半身穿着的裙类半身裙、连衣裙、吊带裙与裤裙区分：无独立裤腿 = 裙装
外套穿在最外层的服饰风衣、大衣、羽绒服、夹克、皮衣与厚卫衣区分：设计为外穿、有门襟 / 拉链 = 外套

判定规则：颜色标注以主色调为准；多色服饰按占比最大的颜色标注；渐变色按中间色标注；环境光影响明显时以标准色卡比对结果为准。

06 / 对错判断

标注对错判断案例

质检工作的核心能力 —— 点击展开判断结果、判断依据与处理方式

✕ 标注错误 严重错误 · 品类判断错误
判断依据
卫衣通常有帽绳 / 罗纹收口 / 棉质抓绒内里；毛衣为针织材质、有明显针织纹理。两者材质与结构不同，必须区分，不能以「看起来都厚」作为判断依据。
处理方式
打回返工 + 记录错误 + 对标注员开展易混淆品类专项培训，并在下次试标中加入该组合的对照题。
✕ 不合格 严重错误 · AIGC 质量问题
判断依据
AIGC 质量评估中「人物结构」占 30% 权重，手指畸形是最常见的 AI 生成瑕疵，必须判为不合格。服饰标注正确不能抵消画面本身的质量缺陷，整图不能流入训练集。
处理方式
标记为「AIGC 质量不合格 - 手部畸形」，剔除出训练数据集，并同步给生成侧用于模型调优。
⚠ 不准确 一般错误 · 属性标错
判断依据
雾霾蓝带有明显灰调与朦胧感，与高饱和度的浅蓝区别明显。若标注标准中存在「雾霾蓝」这一细分色标签，应标为雾霾蓝；若标准中只有基础色，才可归为浅蓝。
处理方式
确认标准色卡后修正；若同类偏差反复出现，组织颜色标准对齐培训并补充色卡比对示例。
✕ 不合规 严重错误 · 图文不一致未识别
判断依据
AIGC 标注任务中图文一致性占 20% 权重。标注员不仅要按图标注，还要核对图片与文字描述是否一致；图文不符的图片应标记为「图文不一致」，而不是仅按图片打标。
处理方式
标记为「图文不一致」并反馈给数据提供方核实，不进入训练集；同时在复核清单中增加「描述字段交叉核对」检查项。
